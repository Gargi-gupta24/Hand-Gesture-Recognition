# ✋ Hand Gesture Recognition using Deep Learning
This project was developed as part of **Task-01 of the Machine Learning Internship at Prodigy Infotech**. The objective of this project is to build a real-time Hand Gesture Recognition System capable of identifying and classifying hand gestures using Deep Learning and Computer Vision techniques.
The system utilizes a **Convolutional Neural Network (CNN)** for gesture classification and integrates **OpenCV** for image processing and webcam-based gesture detection. This project demonstrates the practical implementation of AI-powered vision systems for real-time gesture recognition.

## 🎯 Objectives

* Collect and preprocess hand gesture images
* Train a CNN model for gesture classification
* Implement real-time gesture detection using a webcam
* Evaluate model performance
* Predict and classify different hand gestures
